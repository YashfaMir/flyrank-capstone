# FlyRank Capstone

A capstone project focused on building a modern web application with a clean, maintainable codebase.

## Overview

FlyRank Capstone is an academic project that applies front-end and back-end web development practices to deliver a structured, production-ready application. The repository is organized for clarity, version control, and collaborative development.

## Tech Stack

| Layer | Technologies |
|-------|--------------|
| Front-end | HTML, CSS, JavaScript |
| Back-end | Node.js |
| Tooling | Git, GitHub |

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- [Git](https://git-scm.com/)

### Installation

```bash
git clone https://github.com/YashfaMir/flyrank-capstone.git
cd flyrank-capstone
```

Additional setup steps will be added as the project structure is defined.

## Project Conventions

- Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages
- Write clean, readable code
- Keep documentation up to date
- Use AI-assisted tools for code review and documentation where helpful
