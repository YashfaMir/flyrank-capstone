## Conventions
- Use Conventional Commits.
- Write clean and readable code.
- Keep the README updated.
- Use AI for code review and documentation.

## Workflow Rules Learned
- Validation logic must be separated into reusable, testable functions instead of being embedded directly in UI scripts.
- Every form input must have a semantic label and validation feedback that is visible and announced accessibly to assistive technology.
- Validation changes must include tests for empty values, whitespace-only values, invalid inputs, and valid submissions.
- Help text must not use error styling or be hidden from assistive technology unless it is intentionally decorative.
- New form features must include explicit edge-case handling for empty, whitespace-only, and malformed user input before submission is allowed.
- Review must check for dead code or placeholder objects that are not part of the actual final behavior.
